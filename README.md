## 📂 Laboratory Catalog

### 🌐 Lab 1: HTML Basics & Tables
- **Lab 1.1**: Design side menu using list (Computers & Accessories, Price with rupee signs) in a 2-column layout.
- **Lab 1.2**: Design first page of Faculty of Technology and Engineering (MSU Baroda) using HTML `<table>` elements.

### 📄 Lab 2: Web Structures, Forms & HTML5
- **Lab 2.1**: Design static website structure with Header, Left sidebar (`Home`, `About Me`, `Contact us`), and Content pane.
- **Lab 2.2**: Student registration form using `<form>`, `<input>`, `<textarea>`, `<button>`, `<select>`, `<option>` with full field validation.
- **Lab 2.3**: MSU Baroda Home page using semantic HTML5 tags with an embedded campus tour video using the `<video>` tag.

### 🎨 Lab 3: CSS & Bootstrap
- **Lab 3.1**: Vertical navigation bar in olive green using CSS.
- **Lab 3.2**: Horizontal navigation bar in olive green using CSS.
- **Lab 3.3**: Art and craft photo album gallery using Bootstrap 5 cards.
- **Lab 3.4**: Student academic marksheet with SGPA, grades, and summary using Bootstrap tables.
- **Lab 3.5**: Employment application form matching the scanned paper specification.
- **Lab 3.6**: Flipkart home page with sticky navbar and Bootstrap category dropdown menus.

### ⚡ Lab 4: JavaScript & DHTML
- **Lab 4.1**: HTML5 video player with JavaScript play/pause and dimension controls (Small, Normal, Large).
- **Lab 4.2**: DHTML typewriter effect appending text dynamically via JavaScript timers.
- **Lab 4.3**: Username and password credential validator enforcing length and character rules.
- **Lab 4.4**: JavaScript vowel finder (locates first/last occurrence of `'a'` and extracts substring between them).
- **Lab 4.5**: Keyboard event handler showing keyCode, announcing vowel presses, and turning background blue on release.
- **Lab 4.6**: Interactive canvas snowfall particle simulation using JavaScript.

### 💫 Lab 5: jQuery & Animations
- **Lab 5.1**: Panel sliding animation using jQuery `slideToggle('slow')`.
- **Lab 5.2**: Move a `<div>` 250 pixels to the right using jQuery `animate()`.
- **Lab 5.3**: Animate multiple properties (`opacity: 0.4`, `height: 500px`, `width: 500px`) using jQuery `animate()`.
- **Lab 5.4**: Smoothly enlarge text `fontSize: 100px` with duration `'slow'` using jQuery `animate()`.
- **Lab 5.5**: Interactive cartoon animation with jump, roll, and dance actions using jQuery.

### 🔄 Lab 6: AJAX
- **Lab 6.1**: Real-time stock market tracker fetching stock rates from `stocks.txt` via AJAX `XMLHttpRequest`.
- **Lab 6.2**: Live cricket match scorecard fetching dynamic data from `score.json` via AJAX.
- **Lab 6.3**: Digital server clock syncing with server timestamp response headers via AJAX polling.

### 📑 Lab 7: XML, XSD & XSLT
- **Lab 7.1**: Cricket players record XML validated with XML Schema (`players.xsd`).
- **Lab 7.2**: Semester marksheet XML transformed into an XHTML report table using XSLT (`marksheet.xsl`).
- **Lab 7.3**: Book collection XML validated with schema constraints and ISBN regex (`books.xsd`).
- **Lab 7.4**: XSLT filter (`<xsl:if test="price &lt; 300">`) printing affordable products from `item.xml`.
- **Lab 7.5**: Book record XML rendered into an XHTML tabular structure using `bookrecord.xsl`.

### 🟢 Node.js Lab
- **Node-1**: Custom Node.js area calculation module (`areaModule.js`) for circle, rectangle, and square used in HTTP server.
- **Node-2**: Node.js program reading `number.txt` via `fs.readFile` to determine Armstrong number property.
- **Node-3**: Node.js HTTP server reading `student.json` and rendering student information by PRN query in a table.
